# Zerodha – Trading Platform Clone

A full-stack stock trading platform inspired by Zerodha, built using the MERN stack (MongoDB, Express.js, React.js, and Node.js).

The application provides user authentication, account management, and an interactive trading dashboard with stock market data visualization.

## Features
- User registration and login
- Secure password hashing using bcrypt
- JWT-based authentication
- Interactive trading dashboard
- Stock portfolio and holdings management
- Real-time style market data visualization
- Responsive user interface

## Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT, bcrypt
- **Libraries:** Axios, Chart.js, Material UI

## Getting Started
Clone the repository, install dependencies in the respective project directories, configure environment variables, and run the frontend and backend servers.
